# Public Images

## English

This folder contains logos, flags, profile fallbacks, and other image assets served directly from `/images`.

Expected fallback:

- `default_user.jpg`: square JPEG profile fallback, ideally at least 200x200 and under 50 KB.

Keep social/share images consistent with `app/opengraph-image.tsx` and metadata in route files.

## 한국어

이 폴더는 `/images` 경로로 직접 제공되는 로고, 국기, 프로필 fallback, 기타 이미지 에셋을 담습니다.

필수 fallback:

- `default_user.jpg`: 정사각형 JPEG 프로필 fallback 이미지. 권장 크기는 200x200 이상, 파일 크기는 50 KB 이하입니다.

소셜 공유 이미지는 `app/opengraph-image.tsx`와 각 route metadata 설정과 일관되게 유지합니다.
