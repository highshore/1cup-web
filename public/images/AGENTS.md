# Agent Guide For `public/images/`

## English

- Keep logo and flag paths stable; navigation and metadata depend on them.
- Use descriptive lowercase filenames for new assets.
- Avoid replacing brand assets with unrelated placeholders.

## 한국어

- 로고와 국기 경로는 안정적으로 유지합니다. 내비게이션과 metadata가 해당 경로에 의존합니다.
- 새 asset은 설명적인 소문자 파일명을 사용합니다.
- 브랜드 asset을 무관한 placeholder로 교체하지 않습니다.
