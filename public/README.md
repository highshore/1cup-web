# Public Assets

## English

`public/` contains files served directly from the site root. Paths are referenced as `/images/...`, `/assets/...`, `/scripts/...`, and similar absolute public URLs.

- `assets/`: page media such as homepage video and guide/blog assets.
- `images/`: logos, flags, and fallback images.
- `animations/`: animation assets.
- `scripts/`: browser-loaded scripts such as audio worklets.

## 한국어

`public/`는 사이트 루트에서 직접 제공되는 파일을 담습니다. 경로는 `/images/...`, `/assets/...`, `/scripts/...`처럼 public 절대 URL로 참조합니다.

- `assets/`: 홈페이지 영상, guide/blog 관련 미디어.
- `images/`: 로고, 국기, fallback 이미지.
- `animations/`: 애니메이션 에셋.
- `scripts/`: audio worklet 같은 브라우저 직접 로드 스크립트.
