# Agent Guide For `public/`

## English

- Do not rename public assets without updating every absolute URL reference.
- Prefer compressed assets with stable filenames for user-facing media.
- Keep browser-loaded scripts dependency-free and compatible with direct loading.

## 한국어

- public asset 이름을 바꿀 때는 모든 절대 URL 참조를 함께 수정합니다.
- 사용자에게 보이는 미디어는 압축된 파일과 안정적인 파일명을 우선 사용합니다.
- 브라우저에서 직접 로드하는 스크립트는 의존성을 최소화하고 직접 로드 가능하게 유지합니다.
