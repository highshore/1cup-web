# Scripts

## English

This folder contains local operational scripts that are not part of the runtime app.

- `export-articles-to-csv.mjs`: reads Firestore `articles` documents and writes `articles_export.csv` at the repository root.

Run scripts from the repository root so relative output paths are predictable.

## 한국어

이 폴더는 런타임 앱에 포함되지 않는 로컬 운영 스크립트를 담습니다.

- `export-articles-to-csv.mjs`: Firestore `articles` 문서를 읽어 저장소 루트의 `articles_export.csv`로 저장합니다.

상대 출력 경로가 예측 가능하도록 저장소 루트에서 스크립트를 실행하세요.
