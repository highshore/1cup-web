# Meetup Route

## English

`app/meetup` renders meetup discovery and event browsing. Most domain logic lives in `app/lib/features/meetup`; this route should focus on page-level layout, fetching orchestration, and event card presentation.

## 한국어

`app/meetup`는 밋업 탐색과 이벤트 목록 화면을 렌더링합니다. 대부분의 도메인 로직은 `app/lib/features/meetup`에 있으며, 이 라우트는 페이지 레이아웃, fetch 흐름, 이벤트 카드 표시를 중심으로 유지합니다.
