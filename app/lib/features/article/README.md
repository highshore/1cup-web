# Article Feature

## English

The article feature contains article data services used by article pages, home topics, and article-related workflows. Keep Firestore article schema handling here when it is article-specific.

## 한국어

article feature는 아티클 페이지, 홈페이지 토픽, 아티클 관련 워크플로에서 사용하는 데이터 서비스를 담습니다. 아티클 전용 Firestore schema 처리는 이 폴더에 유지합니다.
