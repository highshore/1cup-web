# Agent Guide For Shadow Feature

## English

- Keep practice-state transitions predictable; avoid UI changes that interrupt active recording or playback.
- Put feature-only styling in `styles/` and reusable UI in `components/`.

## 한국어

- 연습 상태 전환은 예측 가능하게 유지합니다. 녹음이나 재생 중인 흐름을 방해하는 UI 변경을 피합니다.
- 기능 전용 스타일은 `styles/`, 재사용 UI는 `components/`에 둡니다.
