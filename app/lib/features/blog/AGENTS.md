# Agent Guide For Blog Feature

## English

- Keep blog type changes backward compatible with existing Firestore/exported records.
- Prefer adding formatting helpers in the feature service layer rather than duplicating formatting in route components.

## 한국어

- 블로그 타입 변경은 기존 Firestore/export 데이터와 호환되도록 유지합니다.
- 라우트 컴포넌트에서 포맷팅을 중복하기보다 feature service layer에 helper를 추가합니다.
