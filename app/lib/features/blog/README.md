# Blog Feature

## English

The blog feature contains blog services, components, and types used by `/blog` and blog detail routes.

- `services/`: fetch and transform blog data.
- `components/`: reusable blog UI components.
- `types/`: blog data contracts.

## 한국어

blog feature는 `/blog`와 블로그 상세 라우트에서 사용하는 서비스, 컴포넌트, 타입을 담습니다.

- `services/`: 블로그 데이터 조회와 변환.
- `components/`: 재사용 가능한 블로그 UI 컴포넌트.
- `types/`: 블로그 데이터 계약.
