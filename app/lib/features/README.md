# Feature Modules

## English

Feature modules isolate domain logic from route files. Each feature should keep its own components, services, types, scripts, styles, and utilities when those files are not broadly reusable.

Current feature areas:

- `article/`: article data services.
- `blog/`: blog listing, detail support, and blog types.
- `home/`: homepage stats, topics, and display components.
- `meetup/`: meetup events, leaderboards, user profiles, and Firestore mapping.
- `shadow/`: shadowing practice UI support.

## 한국어

기능 모듈은 라우트 파일에서 도메인 로직을 분리하기 위한 영역입니다. 넓게 재사용되지 않는 컴포넌트, 서비스, 타입, 스크립트, 스타일, 유틸은 각 기능 폴더 안에 둡니다.

현재 기능 영역:

- `article/`: 아티클 데이터 서비스.
- `blog/`: 블로그 목록/상세 지원 및 타입.
- `home/`: 홈페이지 통계, 토픽, 표시 컴포넌트.
- `meetup/`: 밋업 이벤트, 리더보드, 사용자 프로필, Firestore 매핑.
- `shadow/`: 쉐도잉 연습 UI 지원.
