# Agent Guide For Leaderboard Route

## English

- Keep the layout two columns on desktop and one column on mobile unless the user asks otherwise.
- Keep card styling minimal: plain surfaces, subtle borders, simple rows.
- Do not remove display-name masking.
- Keep leaderboard labels localized.

## 한국어

- 사용자가 다르게 요청하지 않는 한 desktop은 2열, mobile은 1열 레이아웃을 유지합니다.
- 카드 스타일은 미니멀하게 유지합니다. plain surface, 은은한 border, 단순한 row를 사용합니다.
- 표시 이름 마스킹을 제거하지 않습니다.
- 리더보드 문구는 다국어 처리를 유지합니다.
