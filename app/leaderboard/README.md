# Leaderboard Route

## English

`app/leaderboard` renders public meetup participation rankings. Data comes from `app/lib/features/meetup/services/meetup_service.ts`.

The design should stay simple, scannable, and privacy-aware. Public names are masked before display.

## 한국어

`app/leaderboard`는 공개 밋업 참여 랭킹을 렌더링합니다. 데이터는 `app/lib/features/meetup/services/meetup_service.ts`에서 가져옵니다.

디자인은 단순하고 훑어보기 쉬우며 개인정보를 고려해야 합니다. 공개 표시 이름은 화면에 보여주기 전에 마스킹합니다.
