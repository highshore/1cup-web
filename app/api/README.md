# API Routes

## English

`app/api` contains Next.js route handlers used by the app for server-side data access and client refresh endpoints.

Current routes:

- `home-stats`: homepage aggregate counts.
- `home-topics`: featured homepage topic/article data.

## 한국어

`app/api`는 앱에서 사용하는 Next.js route handler를 담습니다. 서버 측 데이터 접근과 클라이언트 refresh endpoint에 사용됩니다.

현재 라우트:

- `home-stats`: 홈페이지 집계 수치.
- `home-topics`: 홈페이지 추천 토픽/아티클 데이터.
