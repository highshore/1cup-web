# Agent Guide For Article Components

## English

- Keep article UI components small and focused.
- Do not move article-only visual constants into global constants unless another feature needs them.
- Preserve Korean translation warning behavior unless the user asks for a product change.

## 한국어

- 아티클 UI 컴포넌트는 작고 명확한 책임을 갖게 유지합니다.
- 다른 기능에서 필요하지 않은 아티클 전용 시각 상수는 global constants로 옮기지 않습니다.
- 사용자가 제품 변경을 요청하지 않는 한 한국어 번역 경고 동작을 유지합니다.
